<ul class="tc-software-list">
  <li>
    <strong><a href="https://cran.r-project.org/web/packages/SIHR/index.html">SIHR</a></strong>
    <p>
      R tools for confidence intervals and hypothesis tests for low-dimensional objectives in one- and two-sample
      high-dimensional regression, including linear and quadratic functionals, treatment effects, inner products, and distances.
      Supports linear, logistic, alternative logistic, and probit models.
    </p>
  </li>
  <li>
    <strong><a href="https://github.com/Captainjingle/gmm">CHIME</a></strong>
    <p>A MATLAB implementation of CHIME, a clustering procedure for high-dimensional Gaussian mixtures.</p>
  </li>
  <li>
    <strong><a href="https://github.com/jingmafdu/TestBMN">TestBMN</a></strong>
    <p>R functions for differential Markov random field analysis and the associated multiple-testing procedure.</p>
  </li>
  <li>
    <strong><a href="https://github.com/hyunseungkang/invalidIV">invalidIV</a></strong>
    <p>R functions for linear instrumental-variables analysis when some candidate instruments may be invalid.</p>
  </li>
  <li>
    <strong><a href="https://cran.r-project.org/web/packages/sisVIVE/index.html">sisVIVE</a></strong>
    <p>An R package for selecting invalid instruments and estimating causal effects from a candidate instrument set.</p>
  </li>
  <li>
    <strong><a href="http://www-stat.wharton.upenn.edu/~tcai/paper/Softwares/PheWAS-Multiple-Testing-Matlab-Code.txt">PheWAS</a></strong>
    <p>A MATLAB implementation of a multiple-testing procedure for phenome-wide association studies.</p>
  </li>
  <li>
    <strong><a href="http://www-stat.wharton.upenn.edu/~tcai/paper/Softwares/capme_1.3.tar.gz">CAPME</a></strong>
    <p>An R package for precision-matrix estimation while adjusting for covariates.</p>
  </li>
  <li>
    <strong><a href="https://cran.r-project.org/web/packages/flare/index.html">CLIME</a></strong>
    <p>
      A fast implementation of the CLIME estimator for sparse precision matrices is available through the <em>flare</em>
      package. The <a href="http://www-stat.wharton.upenn.edu/~tcai/paper/Softwares/CLIME-R-Package/clime_0.2.tar.gz">original R package</a>
      and <a href="/assets/pdf/software/clime-manual.pdf">manual</a> are also archived.
    </p>
  </li>
  <li>
    <strong><a href="http://www-stat.wharton.upenn.edu/~tcai/paper/Softwares/Covariance-Function-R-Package/ssfcov_1.0.zip">ssfcov</a></strong>
    <p>An R package for covariance-function estimation.</p>
  </li>
  <li>
    <strong><a href="http://www-stat.wharton.upenn.edu/~tcai/paper/Softwares/FDR-HMM-R-Code">FDR-HMM</a></strong>
    <p>R code for data-driven multiple testing with dependent observations under a hidden Markov model.</p>
  </li>
  <li>
    <strong><a href="http://www-stat.wharton.upenn.edu/~tcai/paper/Softwares/FDR-R-Code.zip">FDR</a></strong>
    <p>R code for the adaptive multiple-testing procedure developed by Sun and Cai.</p>
  </li>
</ul>
